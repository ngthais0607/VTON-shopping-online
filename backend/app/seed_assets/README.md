# TrueLook demo illustrations

These 12 original SVG illustrations are bundled with the seed. Each depicts clothing laid out alone on a neutral background; no network, stock-photo service or model photograph is needed. The SVG source is editable and uses no external fonts, links or scripts.

Seed uploads them to `products/demo/<product-slug>.svg` in the configured MinIO bucket. Re-running seed restores missing objects without duplicating catalog rows, orders or stock deductions.

These are labeled demo illustrations, not product photographs. VTON model acceptance and image quality remain unverified. Replace corresponding assets with real, licensed flat-lay garment photographs and update their extension/content type before evaluating a VTON model; product IDs and variants need not be reseeded.
