# TrueLook design references

The current direction is Champagne Editorial: Cormorant Garamond and Inter, white and warm ivory surfaces, charcoal text, champagne accents, thin rules and restrained motion. The earlier olive/Bricolage concept is superseded.

- [Storefront brief](luxury-brief.md): approved palette, typography, layout and illustrative campaign asset.
- [Admin scope](admin-luxury-scope.md): administration screens and interaction constraints.
- [Editable Figma references](https://www.figma.com/design/nPNU56MDd9fXl0t7xGHOJO): current revision on `02 — Champagne Editorial`; foundations on the Design System page.

Collection behavior retains grouped parent/child categories, collapsible facets, mobile filters on demand, search, sorting, count and reset. Product rails provide Pause/Play and manual navigation with reduced-motion support. Interface copy is English; stored product names and user data keep their original language.

These files are design references, not evidence that the current application passed browser acceptance. Use the repository test commands for current verification. Superseded olive screenshots and the old integration run report are preserved in the ignored local archive `demo-backups/docs-cleanup-20261101/docs/design-review/`; they are not part of the current design deliverable.
